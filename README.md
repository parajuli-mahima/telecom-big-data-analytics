# Telecom Customer Churn Analysis

## Overview
This project analyzes telecom customer data to predict churn and uncover patterns in customer behavior, network congestion, and profitability using PySpark for big data processing and machine learning.

## Dataset
- Raw source: [Telco Customer Churn](https://huggingface.co/datasets/aai510-group1/telco-customer-churn) (Hugging Face)
- Includes customer demographics, service plans, billing, and churn status
- Additional simulated fields: CallDuration, DataUsage, Location, Complaints, SessionCount, CongestionRisk, Cost, Profit
- Cleaned output (`data/telecom_clean.csv`) is included in this repo — generated by running the notebook end-to-end

## Tools & Technologies
- Python
- PySpark (SQL, MLlib)
- Pandas
- Matplotlib, Seaborn
- Hugging Face Datasets
- psutil

## Workflow
- Data loading (Hugging Face → PySpark DataFrame)
- Data cleaning and column standardization
- Feature engineering (Tenure, SessionCount, CongestionRisk, Cost, Profit)
- Missing value handling
- Exploratory Data Analysis (churn distribution, location trends, congestion risk, profitability)
- Correlation analysis and pairplots
- Model training (Random Forest, Logistic Regression, GBT Classifier)
- Model evaluation (accuracy, F1-score, AUC, confusion matrix)
- Performance benchmarking (RDD vs DataFrame vs SQL, CPU utilization, scalability testing)
- Data export (Spark SQL table, CSV)

## Result
The system identifies key churn drivers and predicts customer churn, with Random Forest, Logistic Regression, and GBT models compared on accuracy, F1-score, and AUC. Congestion risk and profit patterns across locations and service plans are also surfaced.
